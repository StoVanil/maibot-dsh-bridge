> **用途**：给 `bridge2/plugins/maibot-dsh-bridge/plugin.py` 直接嵌入。每个 ```text 块就是最终发到 QQ 的原文，

> **占位符**：本版帮助文案**不含**运行时变量；如果后续要带数量/剩余时间等动态内容，再单独约定（别自己塞 `{}`）。

## 一、嵌入约定（给 Lead）

### 1.1 常量与入口

```
HELP_DEFAULT        →  /dsh help（不带场景）、/dsh、/dsh 帮助、/dsh ?
HELP_TOPIC          →  /dsh help 话题
HELP_FILE           →  /dsh help 文件
HELP_PERMISSION     →  /dsh help 权限
HELP_EXPERIMENT     →  /dsh help 实验
HELP_TROUBLE        →  /dsh help 排障
HELP_ALL            →  /dsh help 全部
```

建议匹配：

```python
m = re.match(r"^(?:help|帮助|\?)(?:\s+(?P<scene>.+))?$", body.strip(), re.IGNORECASE)
# 没有 body / 没有 scene → HELP_DEFAULT
# scene 归一化（去空格、小写、全角转半角）后查下表；认不出就回 HELP_DEFAULT + 一句"没这个场景"
```

## 二、文案块（可直接粘贴）

### `HELP_DEFAULT` · 默认总览（14 行）

```text
🛠 /dsh 用法（大肥鱼的活儿都收在这儿啦～）
  /dsh <任务>                     把活儿交给大肥鱼（没话题会自动开一个；默认不限时）
  /dsh #3 <任务>                  指定在 #3 话题里干
  /dsh peek | status             偷看大肥鱼现在在干啥 / 刚刚干了啥

  /dsh files                      你的文件柜（看 / 删 / 取回 / 建文件夹）
  /dsh 审批                       权限申请单和已授权的人（审批人）
  /dsh 实验开启                   让墨自己调度大肥鱼（最长 24 小时，稳一点再开～）
  /dsh help                       就是这段啦
想看细的，按场景翻：
  /dsh help 话题   /dsh help 文件   /dsh help 权限
  /dsh help 实验   /dsh help 排障   /dsh help 全部
发 /dsh help 看全部入口～

### `HELP_TOPIC` · 话题（10 行）

```text
📚 话题（一个话题 = 一条持久会话 + 一个独立目录～）
  /dsh new                       开个新话题，之后的话都落进去
  /dsh list                      看有哪些话题、现在在哪个
  /dsh list #3                   看 #3 详情并切过去
  /dsh rename <名字>             给当前话题改个名（≤12 字；同 /dsh set）
  /dsh archive [#3]             收进档案袋变只读（同 /dsh del；7 天后销毁）

· 24 小时没派活会自动开新话题；改名不动目录和会话
· 正文以 new/del 开头会被误判，加 -- 强制当任务：/dsh -- new 一个页面
发 /dsh help 看全部入口～
```

## 四、文案/术语决策（已与 Lead 对齐）

1. **`/dsh status`** = `/dsh peek` 的英文别名（看运行/空闲/最近一次结果）；**`/dsh queue`** = 排队列表（第几位、几条），与 `peek/stop` 同组，不混进话题。
2. **话题英文别名**：帮助里以 `/dsh rename`、`/dsh archive` 为主展示，括号注明「同 `/dsh set`」「同 `/dsh del`」，两个写法都认。
3. **文件**：根目录是工作区根 `files/<QQ号>/`，跨话题共用；只有主人（QQ 2953679189）能 `/dsh files all`、`/dsh files users`。帮助里不写死主人 QQ（避免公开号），只说「主人专用」。
4. **文件保留**：长期保留、自己 `/dsh files rm` 删；单文件 ≤ 50 MB（`dsh.upload_max_mb`）；暂不加自动清理，文案里留一句「以后可能加配额 / 自动清理」。
5. **实验模式**：v0.13.0 起不再需要先去 MaiBot 面板开总开关，QQ 里 `/dsh 实验开启` → `/dsh 实验确认 <6位码>` 即可，最长 24 小时、到期自动关。
6. 帮助正文**不出现**内部实现名词（save/restore、session-id、uploads 路径等），只留用户能操作的命令和结果。
