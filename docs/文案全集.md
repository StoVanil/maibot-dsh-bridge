# 你在「麦麦 × 大肥鱼 桥」里工作

这个工作区由 MaiBot 的 maibot-大肥鱼-bridge 插件给 QQ 用户建的任务目录：你替用户在服务器上干活，最终回答会被转给用户。

## 需要用户拍板时：先调 ask 工具（重要）

需要用户决定（选方案、确认要不要删/改、缺关键信息）时，**不要自己猜**：

1. 调用工具 `mcp__ask__ask_user`（参数：`question` 必填，`options` 可选，`note` 可选）。
   它会阻塞，直到用户在 QQ 里回答，然后把答案作为工具结果返回给你；你接着做即可。
2. 如果它返回超时，按提示处理（说明卡点、先做能独立完成的部分）。
3. 如果该工具不可用（不存在 / 报错），再退回到：在工作区写 `ask-requests/<短名>.json`
   （`{"question": "...", "options": ["..."], "note": "..."}`），然后结束这一轮，桥会用同一会话续跑你。

## 交付文件：用 present

要交给用户的文件（文档、压缩包、图片等）用 `present` 声明：
`present({"files": [{"path": "报告.docx", "description": "说明"}]})`。
桥会把这些文件发回 QQ；交付物必须在你当前工作区里（或 session 可访问的普通文件）。

不要自己 pip 安装，也不要用别处找的 python。

### H07  分场景帮助：全部  `HELP_ALL`
位置：plugin.py · 帮助常量 HELP_ALL
场景：/dsh help 全部（别名：all/所有/7）
```text
🗂 /dsh 全部用法（按场景排好，慢慢翻～）

【开工干活】
  /dsh <任务>                    交给大肥鱼（没话题会自动开一个；默认不限时）
  /dsh #3 <任务>                 指定在 #3 话题里干
  /dsh --timeout 600 <任务>      给这单设个时间上限（默认不设）
  /dsh -- new 一个页面           正文以 new/del 开头时，用 -- 强制当任务
【盯进度 · 叫停】
  /dsh peek | status            偷看现在在跑啥 / 刚跑完啥
  /dsh queue                    看排队列表（第几位、几条）
  /dsh stop                     喊停当前活儿（做好的文件会尽量留给你）
  /dsh stop 全部                连排队的一起清掉
【话题】
  /dsh new                      开个新话题
  /dsh list                     看话题列表并切过去
  /dsh list #3                  看 #3 详情
  /dsh rename <名字>             改当前话题名（同 /dsh set）
  /dsh archive [#3]             收进档案袋，7 天后销毁（同 /dsh del）
  /dsh restore #3               从档案袋捞回来
【文件】
  /dsh files                    自己的文件柜
  /dsh files send <序号|名字>    把文件重新发回聊天
  /dsh files rm <序号|名字>      删自己的文件
  /dsh files mkdir <名字>        建子文件夹
  /dsh files all                主人：看所有人的文件
  /dsh files users              主人：看各人占用
【权限 / 审批】
  /dsh 审批 | 授权列表           待审批申请 + 已授权的人（审批人）
  /dsh 批准 A1 [小时]            批准（省略=默认时长，0=永久）
  /dsh 拒绝 A1 [理由]            驳回
  /dsh 撤销 <QQ>                 收回某人的权限
【实验模式】
  /dsh 实验开启                  生成 6 位确认码（10 分钟内有效）
  /dsh 实验确认 <6位码>           对上就开，最长 24 小时
  /dsh 实验状态                  看还剩多久
  /dsh 实验关闭                  提前收摊
【小贴士】
  · 命令只在私聊生效；结果默认直接发聊天，太长会落成 .md 文件
  · 没有权限的人发 /dsh 会先变成申请单，等审批人批
  · 文件按 QQ 号分目录，别人看不到你的；单文件最大 50 MB
  · 想看细的：/dsh help 话题 / 文件 / 权限 / 实验 / 排障
发 /dsh help 看全部入口～
```
